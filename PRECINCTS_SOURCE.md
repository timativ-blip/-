# Источник списка УИК

Ожидаемый источник: Избирательная комиссия Московской области — http://www.moscow_reg.izbirkom.ru/

Проверка 15 сентября 2026 года: HTTP и HTTPS недоступны через веб-инструмент; прямое открытие в браузере завершилось сообщением «Не удается получить доступ к сайту».

Официальный полный список не импортирован. `precincts.json` содержит только три демонстрационных записи, не реальные данные ИКМО. Production-запуск с ними блокируется.

После получения перечня замените записи и укажите здесь точный URL документа, дату документа, дату получения, число импортированных УИК и охват муниципалитетов. Не считайте произвольный диапазон номеров достоверным перечнем участков.
