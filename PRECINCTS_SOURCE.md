# Список ТИК и УИК

Источник: предоставленный пользователем файл «ТИК и УИК.pdf», 228 страниц.
Дата импорта: 15 сентября 2026 года.
SHA256: `a666bedca50c607d59ae1b977a1cd2b336b39f146e0a061ebcf961ffd5ec94b4`.

Импортированы все 56 ТИК и 3 925 УИК. Число распознанных УИК совпадает с числом упоминаний участковых комиссий в PDF; повторяющихся номеров нет. Названия и принадлежность к ТИК сохранены из документа. Актуальность документа определяется его составителем; отдельной сверки с сайтом комиссии при этом импорте не выполнялось.

`precincts.json` — массив объектов `id`, `label`, `tik`. ID вида `mo-uik-1259` стабилен по номеру УИК. ТИК выбирается первым, затем показываются только его УИК; доступен поиск по номеру. При смене ТИК выбор УИК сбрасывается.

Повторный импорт (нужен пакет pypdf):

```sh
python scripts/import_precincts.py '/путь/ТИК и УИК.pdf' precincts.json
```

В Google Таблицу ТИК записывается в новый столбец M, остальные столбцы остаются на прежних местах. Старые строки автоматически не дополняются. Старые демонстрационные УИК удалены из выбора; ранее сохранённые офлайн анкеты с ними по-прежнему принимаются сервером.

Экспорт сверяет ID анкет с колонкой A перед записью: после сброса SQLite новые анкеты идут после существующих строк. Для одной вкладки нужен один процесс экспорта (`--workers 1`); нельзя одновременно запускать локальный сервер и Render с экспортом в одну вкладку.
